# 再生能源售電業申照輔導暨申請服務契約

立契約人：

甲方：【客戶完整名稱】

乙方：優選股份有限公司

甲方委託乙方提供再生能源售電業申照輔導暨申請服務。雙方同意，乙方應以甲方準備實際經營之售電事業及甲方確認之資料與決策為基礎，協助建立申請架構、撰寫及整合核心申請文件、辦理正式送件並提供審查與補件支援。雙方約定如下。

### 本案選用服務模組

- ☐ **第 0 階段｜前期事業規劃**：NT$150,000 未稅（選配）
- ☒ **標準完整申照專案**：NT$450,000 未稅（固定核心專案，包含第 1 階段及第 2 階段）

本案服務模組以本欄勾選結果為準。標準完整申照專案固定選用；第 0 階段欄位如未勾選，即視為甲方未選用該模組。第 0 階段為標準完整申照專案之前置選配，並非替代方案。

## 第一條 定義

1. **本服務**：指乙方依本契約及附件一「再生能源售電業申照輔導暨申請服務工作範圍書」（以下稱 SOW）提供之選用服務模組；標準完整申照專案包括需求訪談、營運資訊盤點與收斂、申請文件撰寫與整合、預估財務資料協作、正式送件、審查意見處理、補件及進度追蹤服務。
2. **第 0 階段**：指甲方選用之「前期事業規劃」模組，由乙方就需決策之法人、商業模式、電源、客戶、營運、組織及財務等事項提出方案與不同觀點、進行比較分析及協助決策；其成果定位為前期事業規劃與決策建議。
3. **第 0 階段完成**：指乙方已完成並交付《前期事業規劃與決策建議》或功能相同之正式成果，並已完成 Review & Decision 會議。甲方是否決定申請、決定不申請、採用乙方建議之特定方案或作成任何特定商業決策，均非第 0 階段完成之必要條件。
4. **第 1 階段**：指標準完整申照專案之「申照建置」階段，自標準完整申照專案正式啟動起，至乙方完成 SOW 所定第 1 階段成果、形成可進入正式主管機關申請程序的第一版完整申請架構，並交付甲方確認之期間。
5. **第 1 階段完成**：指乙方已依 SOW 完成第 1 階段約定成果，形成可進入正式主管機關申請程序的第一版完整申請架構，並交付甲方確認；甲方已確認，或依第七條視為完成確認。主管機關是否受理、接受或核准，不屬第 1 階段完成之要件。
6. **第 2 階段**：指標準完整申照專案之「正式申請及審查支援」階段，於第 1 階段完成後，由乙方辦理正式主管機關送件、申請窗口往來、審查意見整理與解析、回覆內容準備、文件修正、補件、進度追蹤及合理範圍再次修正之期間。
7. **主管機關申請程序完成**：指乙方已完成 SOW 約定之送件、審查意見處理及補件支援，且主管機關已就本次申請作成核准、駁回、不予受理、退件或其他足以終結本次申請程序之正式處置。甲方主動中止、本契約提前終止，或程序終結係因可歸責於乙方之重大違約所造成時，不視為第三筆正常付款節點；應依本契約之重大違約、改善、責任、終止及結算條款辦理。
8. **交付成果**：指 SOW 所列由乙方製作、整合或提供之文件、資料架構、申請版本、審查意見整理及其他成果。
9. **工作日**：指中華民國政府行政機關之正常辦公日，不含星期六、星期日及依法放假日。
10. **主管機關**：指依法管轄本次再生能源售電業申請之機關；其名稱、權限及申請要求依辦理時之現行法令、規定及實務為準。

## 第二條 契約性質與角色分工

1. 本契約為乙方提供專業顧問、文件及申請程序服務之契約。乙方得依專業判斷安排工作方法、執行順序、人員配置及作業時間。
2. 甲方為申請主體及未來售電事業之經營決策者，應就事業定位、商業模式、電源、售電對象、組織、人力、財務、資金、交易假設及最終申請內容作成決定並負責。
3. 乙方依甲方提供及確認之真實營運規劃製作申請文件，不負責替甲方虛構僅為通過審查之內容。
4. 除甲方另以書面明確授權外，乙方無權以甲方名義簽署文件、承諾商業條件、作成法律意思表示、收受款項或對第三人負擔義務。
5. 甲乙雙方間不因本契約成立僱傭、勞動派遣、合夥、共同經營、經銷、代理或其他類似關係。

## 第三條 契約期間

1. 本契約自雙方簽署之日起生效。甲方選用第 0 階段者，第 0 階段於本契約成立日或雙方約定之第 0 階段啟動日正式啟動；標準完整申照專案則於第 0 階段完成且甲方進入第 1 階段時正式啟動。甲方未選用第 0 階段者，標準完整申照專案於本契約成立日或雙方約定之啟動日正式啟動。各階段啟動均不以乙方實際收到對應款項為條件。
2. 本契約有效至主管機關申請程序完成、雙方書面合意終止，或依本契約約定提前終止之日止。
3. 乙方應以合理專業注意義務及合理效率推進第 0 階段，不承諾固定完成天數。因甲方資料、決策、內部窗口、利害關係人、會議安排、第三人或其他非可歸責乙方之因素造成延遲者，時程相應順延。
4. 本契約不設服務年度及自動續約。因甲方配合、主管機關審查、第三方作業、法規變動或其他非可歸責乙方事由所生之期間延長，不構成乙方保證於特定日期完成。
5. 契約終止或屆滿後，保密、智慧財產、費用結算、損害賠償、爭議處理及依其性質應繼續有效之條款仍繼續有效。

## 第四條 服務範圍與 SOW

1. 乙方應依本契約及 SOW 提供本服務。SOW 應至少包括專案目標、第 0 階段選配內容、第 1 階段與第 2 階段服務、交付成果、財務資料責任、甲方配合義務、文件把關、範圍限制、變更管理、完成定義及非結果保證。
2. 標準完整專案以需求與資料蒐集、核心文件撰寫整合，以及正式送件與審查支援為完整最小服務結構。即使部分原始資料或草稿由甲方準備，只要乙方仍負責正式申請，乙方仍應保有合理之審閱、一致性檢查、要求補正及判斷是否適宜送件之專業權限。
3. SOW 未列入之工作，不因與再生能源、售電業或甲方營運相關而自動納入本服務。
4. 取得售電業執照後之實際營運、電能轉供作業及其他營運支援，不包含於本服務；如有需求，由雙方另案議定。
5. 第 0 階段適用於甲方尚未完全確定是否或如何申請售電業、尚未決定申請牌照之法人主體，或售電事業模式仍需管理層作成重大決策之情形。乙方得就商業模式、電源策略、客戶策略、內部營運及商業可行性提出方案與不同觀點、進行比較分析，協助甲方管理層作成決策。
6. 第 1 階段適用於甲方已確定申請售電業、具備基本事業方向，並能提供及確認主要營運事實與假設之情形。乙方負責訪談、盤點、收斂、整合及撰寫；涉及甲方營運、電源、客戶及財務之事實、數據、假設及最終決策，仍由甲方提供或確認。乙方不在第 1 階段代甲方重新作成重大商業模式決策，亦不自行建立甲方之商業收益、成本估算、集團成本或最終財務數值。
7. 甲方未選用第 0 階段時，即確認其已具備足以啟動標準完整申照專案之基本事業方向。標準完整申照專案不包含重新比較重大事業模式、法人主體之重大策略比較、建立全新電源策略、建立全新售電市場策略、替甲方重新設計完整商業模式，或替管理層進行前期事業可行性決策。乙方於第 1 階段仍得提問、檢視明顯矛盾、盤點、收斂、整合及檢查一致性，前述工作不因此視為已包含第 0 階段。
8. 第 0 階段及第 1 階段原則包含 Kick-off、Workshop 及 Review & Decision 三類正式會議節點。Workshop 得依專案實際需要及利害關係人分工安排一場或數場；實際場次由乙方依完成本階段工作之合理需要安排。各會議之具體功能依 SOW 辦理。
9. 因甲方之決策、重大變更或其他非屬原工作範圍之需求而要求增加之會議或重作，不包含於上述標準服務，依第九條變更管理辦理。
10. 本服務原則以視訊會議、電話、電子郵件、線上文件協作或其他合理電子方式遠端執行。因甲方要求或案件實際需要安排乙方前往指定地點提供現場服務時，必要之大眾運輸、計程車、停車、住宿及其他合理差旅支出，由甲方依實際發生負擔或實報實銷；不另行收取固定出席費或現場服務費。現場會議如係因甲方決策、重大變更或範圍外需求所生，仍依第九條辦理。

## 第六條 雙方權利義務

### 一 甲方義務

1. 指定具適當權限之主要聯絡窗口，負責資料提供、內容確認、決策傳達及內部協調。
2. 依乙方提出之合理期限，提供完整、正確、合法、最新且盡量符合未來真實營運之文件、資訊及商業假設。
3. 確認申請主體、事業定位、商業模式、電源、售電對象、組織、人力、交易及最終申請內容。
4. 提供並確認公司或集團人員成本、內部管理成本、系統成本、既有資產、融資成本、會計處理、稅務、內部費用分攤及其他僅甲方掌握之財務會計資訊。
5. 對其提供之資料、指示、決策、商業假設及簽署文件的真實性、完整性、正確性、合法性及最終採用負責。
6. 取得第三方資料、機密資訊或受保密義務拘束資訊供乙方使用或向主管機關提出所需之同意及授權。
7. 依需要完成確認、簽章、用印、付款、委任、授權及其他必要決策，並及時提供主管機關或其他相關主體直接通知甲方之重要資訊。

### 二 乙方義務

1. 依本契約及 SOW，以合理專業注意義務及合理效率提供服務。
2. 依甲方提供及確認之資料，整理營運假設、撰寫與整合核心申請文件；就預估財務內容，乙方得說明常見收入與成本項目、申請資料格式及主管機關通常期待理解之內容，並依甲方提供或確認之數據與假設進行盤點、收斂、一致性檢視及文件整合。
3. 發現資料或文件有明顯缺漏、錯誤、矛盾、不符合申請架構或與已確認營運規劃不一致時，通知甲方補正或確認。
4. 依約辦理或協助辦理正式送件、審查意見整理與解析、文件修正、補件及進度追蹤。
5. 於知悉可能重大影響本次申請之法規、政策或主管機關要求變動時，在合理範圍內通知甲方並說明影響。

## 第七條 交付成果確認及服務完成

1. 第 0 階段完成之認定依第一條及 SOW 辦理。乙方完成並交付約定成果且完成 Review & Decision 會議後，即達成第 0 階段之工作要件；甲方尚未作成特定決策，不影響第 0 階段之完成認定。
2. 甲方應於收到乙方各階段交付成果之日起十個工作日內完成確認或提出具體且合理之修正意見；逾期未提出者，視為該階段交付成果已完成確認。
3. 甲方提出之修正意見應具體指出需修正之內容，並以原服務範圍及已確認之資料、假設與方向為基礎。甲方後續變更已確認事項而造成重大重作者，依第九條辦理。
4. 乙方依約完成特定成果或程序，即視為完成該項服務。後續因甲方資料或決策、第三方未配合、主管機關審查或作業、法規政策變動，或其他非可歸責乙方之事由所生之延遲、修正、補件或不利結果，不影響乙方已完成服務之認定。
5. 第 1 階段完成及主管機關申請程序完成之認定，依第一條及 SOW 辦理。

## 第九條 變更管理及法規變動

1. 甲方提出 SOW 外需求、要求乙方重作原非乙方負責之內容，或變更已確認之申請主體、商業模式、電源策略、售電對象、重大交易假設、財務基礎或其他重要資料而造成重大重作時，乙方得提出範圍、時程及費用調整。

3. 因法令、政策或主管機關要求所生之一般合理表單、格式及補充要求調整，乙方於原 SOW 內合理處理。
4. 前項變動如造成申請架構重大改變、已確認文件大幅重作、新增重大工作或使原商業模式根本無法繼續，乙方得暫停受影響工作並重新評估範圍。雙方得另行書面約定追加服務，或依第十條及第十一條辦理暫停、終止與結算。

## 第十條 服務暫停

1. 甲方未提供必要資料、所提供資料有錯誤或遺漏、逾期、未確認、未簽章或未作必要決策時，乙方得以書面通知暫停全部或部分工作，服務時程並相應順延。甲方逾期支付到期款項時，乙方得以書面通知甲方；甲方經通知後仍未於十個工作日內完成付款者，乙方得暫停全部或部分服務。因付款逾期而暫停者，專案時程相應順延，乙方不負因此造成之送件、補件、申請或其他時程延誤責任。前述暫停不影響乙方就已完成工作或已到期款項之請求。
2. 甲方於第 0 階段完成前主動要求暫緩，且非因乙方可歸責之重大違約者，第 0 階段 NT$150,000 仍為已到期服務費，不退款且不因暫緩而延後付款。暫緩期間原則上以三個月為限；甲方於三個月內恢復者，乙方依原服務範圍繼續執行。暫緩超過三個月者，乙方得依第十一條第四項終止契約，或由雙方另以書面重新確認後續工作安排；第 0 階段尚未完成者，不適用第十一條第五項之 NT$112,500 提前終止服務費。
3. 第 0 階段完成後，甲方因自身原因暫緩進入第 1 階段者，暫緩期間最多三個月。甲方於三個月內恢復並進入第 1 階段者，不適用 NT$112,500 提前終止服務費；暫緩超過三個月，或暫緩期間甲方明確表示不再進入標準完整申照專案者，依第十一條第五項辦理。
4. 甲方於第 1 階段進行中主動要求暫緩，且非因乙方可歸責之重大違約者，甲方應支付 **NT$100,000 未稅**之第 1 階段已投入工作階段結算款。該款同時抵充第五條第一項第二筆 NT$200,000 服務費之一部分。
5. 甲方於前項暫緩日起三個月內恢復履約者，第 1 階段完成時，第二筆服務費僅再支付未抵充之 **NT$100,000 未稅**。本款不增加標準完整申照專案總價，正常完成時總服務費仍為 NT$450,000 未稅。
6. 第 1 階段暫緩超過三個月、暫緩後甲方決定終止，或暫緩期間因法令、政策或主管機關要求變更致原申請無法繼續且非可歸責乙方者，依第十一條第六項辦理。
7. 第 2 階段暫緩期間，已到期款項不受影響。暫緩超過三個月或甲方於暫緩後決定不再續行者，依第十一條第七項辦理。

## 第十一條 契約終止及專案結算

1. 任一方重大違反本契約時，他方得以書面通知並給予十個工作日之改善期限；違約方屆期仍未改善，且已致專案無法合理繼續者，他方得以書面終止本契約。甲方持續或重大逾期付款者，依本項及第十條之通知、改善、暫停與終止機制辦理。
2. 任一方有解散、清算、破產、重整、停止營業、依法應備許可失效致無法履約，或重大違法行為足以使他方承受重大法律風險之情形，他方得不經改善期間，以書面立即終止本契約。
3. 雙方得隨時以書面合意終止本契約，並另行約定終止日、交接及費用結算。
4. 第 0 階段完成前，如甲方主動終止、決定不再繼續，或因可歸責甲方之事由致契約無法繼續，且非因乙方可歸責之重大違約者，第 0 階段 NT$150,000 為已到期服務費，甲方應支付且不得要求退款；除依法應負擔之稅額、已核准代墊及第三方費用外，不另收取第十一條第五項之 NT$112,500 提前終止服務費。
5. 第 0 階段已完成，但甲方其後決定不再進入原已選定之標準完整申照專案，或依第十條第三項暫緩超過三個月，或於暫緩期間明確表示不再進入標準完整申照專案，且非因乙方可歸責之重大違約者，視為甲方提前終止後續標準完整申照專案。除已到期之第 0 階段 NT$150,000 外，甲方另應支付 **NT$112,500 未稅**之提前終止服務費，另加依法應負擔之稅額、已核准代墊及第三方費用。
6. 第 1 階段進行中，如甲方主動終止、因可歸責甲方之事由致乙方依法或依約終止，或發生第十條第六項之情形，且非因乙方可歸責之重大違約者：
   - 第五條第一項第一筆 NT$100,000 為已到期之專案啟動服務費。
   - 甲方另應支付第 1 階段提前終止服務費 **NT$175,000 未稅**。
   - 因此，截至終止日之標準服務費總應結算為 **NT$275,000 未稅**，另加依法應負擔之稅額、已核准代墊及第三方費用。
   - 甲方如已依第十條第四項支付 NT$100,000 階段結算款，該款抵充本項之第 1 階段提前終止服務費；抵充後尚餘 **NT$75,000 未稅**應付。
7. 第 1 階段已完成且第 2 階段已開始後，如有下列情形之一，且非因乙方可歸責之重大違約者：
   - 主管機關提出要求，甲方決定不接受並停止申請。
   - 甲方主動要求暫緩且逾三個月未恢復。
   - 暫緩期間因法令、政策或主管機關要求變更致原申請無法繼續，且非可歸責乙方。
   - 其他由甲方主動中止且非可歸責乙方之合理同類情形。

   前述情形下，第五條第一項第一筆及第二筆合計 NT$300,000 均為已到期服務費，甲方另應支付第 2 階段提前終止服務費 **NT$75,000 未稅**；截至終止日之標準服務費總應結算為 **NT$375,000 未稅**，另加依法應負擔之稅額、已核准代墊及第三方費用。
8. 第四項至第七項之結算機制，不適用於乙方可歸責之重大違約造成專案無法合理繼續，且乙方經第一項期限仍未改善而由甲方終止之情形。此時：
   - 甲方仍應就終止前乙方已完成、可供甲方合理使用且應計價之服務，以及已核准之必要代墊與第三方費用辦理結算。
   - 乙方應返還已收款中可明確歸屬於尚未提供，或因乙方重大違約而無法合理使用之服務部分。
   - 雙方應依已交付成果、工作紀錄、各階段完成程度及預付款歸屬，以誠信原則完成結算。
9. 第 1 階段正式啟動後，第五項 NT$112,500 提前終止服務費不再適用；其後之暫緩、提前終止及結算，完全依第十條第四項至第七項及本條第六項至第八項辦理，不得重複加收 NT$112,500。
10. 契約終止不影響終止前已發生之權利、付款義務及損害賠償請求。乙方應於甲方結清無爭議之到期款項後，以合理方式交付甲方原始提供且仍由乙方持有之案件資料；依法或依內部合規要求須留存者，不在此限。

## 第十二條 保密及公開使用

1. 本契約所稱機密資訊，指任一方因本契約之協商、簽署或履行而自他方取得之未公開資訊，包括但不限於：
   - 公司、股東、組織、營運、系統及內部流程資訊。
   - 電源、發電設備、購電來源、售電客戶及其他交易相對人資訊。
   - 受保密協議或其他保密義務拘束之資訊。
   - 商業模式、價格、交易條件、申請策略及契約內容。
   - 財務、會計、稅務、資金、成本、收入及預估資料。
   - 依法或依其性質應合理認定為機密之其他資訊。
2. 接收方僅得為履行本契約之目的使用機密資訊，未經揭露方事前書面同意，不得向無須知悉之第三人揭露。
3. 接收方得於履行本契約所必要之範圍，向其員工、受任人、專業顧問、協力廠商及主管機關揭露機密資訊，但應使受領者承擔適當保密義務。
4. 下列資訊不受前述限制：接收時已合法公開、非因接收方違約而公開、接收方原已合法持有、自有權揭露之第三人合法取得，或接收方未使用機密資訊而獨立開發之資訊。
5. 因法令、法院或主管機關要求必須揭露時，接收方得在必要範圍揭露；如依法可事先通知，應於揭露前通知揭露方。
6. 任一方未經他方事前書面同意，不得公開使用他方名稱、商標、標誌或合作關係作為行銷、案例或對外宣傳。
7. 本條保密義務於本契約終止或屆滿後持續五年；屬營業秘密或依法應持續保密者，於該資訊喪失機密性前持續有效。

1. 甲方原始提供之資料及其原有智慧財產權，仍歸甲方或原權利人所有。
2. 乙方於本契約成立前已持有，或於履約中形成之通用方法、標準流程、文件架構、範本、工具、公式、模型、資料結構、專業知識及其改良，相關權利仍歸乙方所有。
3. 甲方付清本契約全部到期款項後，得為自身本次申請、內部決策、後續合規及自身售電事業營運目的，使用乙方依甲方個別資料製作之專案交付成果。
4. 除雙方另有書面約定外，前項使用權不包括將乙方通用方法、範本或工具單獨出售、授權、公開散布，或用於向第三人提供相同或類似顧問服務。

## 第十四條 損害賠償及責任限制

1. 任一方違反本契約，經他方書面通知並給予合理改善期間而未改善者，應賠償他方因此所受之直接且可證明之實際損害。
2. 除乙方有故意、重大過失，違反保密義務、侵害智慧財產權，或法律另有不得限制之情形外，乙方因本契約對甲方所負之損害賠償責任總額，以損害事件發生前甲方依本契約已實際支付之服務費總額為上限。
3. 除因一方故意或重大過失所致外，任一方不對他方之間接損害、所失利益、預期交易利益、商譽損失或其他衍生性損害負責。
4. 甲方遲延支付到期款項時，乙方得依法請求遲延利息，並得依第十條暫停服務或依第十一條終止契約。

## 第十五條 不可抗力及其他非可歸責事件

1. 因天災、戰爭、重大疫情、政府行為、重大系統中斷或其他當事人無法合理預見、避免或控制之事件，致任一方不能或遲延履約者，受影響方就該影響範圍不負遲延或損害賠償責任。
2. 受影響方應於合理期間通知他方，說明影響範圍，並採取合理措施降低損害及恢復履約。
3. 事件僅影響部分義務時，未受影響部分仍應繼續履行；付款義務如在事件發生前已到期，不因本條而免除。
4. 法令、政策或主管機關要求變動之工作範圍與費用影響，優先依第九條處理；如因此暫停或終止，依第十條及第十一條結算。

## 第十六條 通知

1. 雙方依本契約所為之通知，應以書面、電子郵件或雙方同意之電子方式送達本契約所載聯絡資料或指定窗口。

## 第十七條 準據法及管轄

1. 本契約以中華民國法律為準據法。

1. 本契約之附件、雙方簽署之選配確認書、變更單及其他明確納入本契約之書面文件，均為本契約之一部分。簽約前提供之報價單僅供內部評估及商務討論，除經雙方於本契約或其他書面文件中明確納入外，不單獨構成本契約之一部分。

   1. 雙方較後簽署之契約修訂或變更單。
   2. 本契約本文。
   3. 雙方簽署之選配確認書或其他個別商業條件確認文件，但僅就其明確約定之價格、付款或個別商業條件優先。

5. 任一條款被認定全部或一部無效時，不影響其他條款之效力；雙方應以最接近原條款目的之有效約定取代。

7. 未經他方事前書面同意，任一方不得移轉本契約之全部或主要權利義務。但因合併、組織重整或營業概括承受所生之移轉，不在此限，移轉方應事前通知他方。
8. 本契約正本一式二份，雙方各執一份；採電子簽署者，電子文件與紙本具有相同效力。
