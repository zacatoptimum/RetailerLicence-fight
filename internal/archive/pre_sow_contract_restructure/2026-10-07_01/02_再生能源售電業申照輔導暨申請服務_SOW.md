# 再生能源售電業申照輔導暨申請服務工作範圍書

## 前言

本工作範圍書為甲方與優選股份有限公司（以下稱乙方）所簽署「再生能源售電業申照輔導暨申請服務契約」（以下稱本契約）之附件，目的在明確界定專案目標、服務內容、交付成果、雙方責任、範圍限制及完成標準。本工作範圍書未定義之名詞，依本契約定義。

### 本案選用服務模組

- ☐ **第 0 階段｜前期事業規劃**：NT$150,000 未稅（選配）
- ☒ **標準完整申照專案**：NT$450,000 未稅（固定核心專案，包含第 1 階段及第 2 階段）

本案服務模組以本欄勾選結果為準。標準完整申照專案固定選用；第 0 階段欄位如未勾選，即視為甲方未選用該模組。第 0 階段為標準完整申照專案之前置選配，並非替代方案。

## 第一條 文件性質

1. 乙方提供之服務為再生能源售電業申照之專業輔導、文件撰寫與整合、申請作業及程序支援。
2. 乙方依甲方提供及確認之真實營運規劃、資料、假設與決策執行服務，不替甲方虛構僅為通過審查之內容。
3. 本工作範圍書所列核心工作構成標準完整專案，不因部分原始資料或草稿由甲方準備而自動刪減。只要乙方仍負責正式申請，乙方即保有合理的審閱、一致性檢查、要求補正及判斷是否適宜送件之專業權限。
4. 本工作範圍書未列入之工作，不因與再生能源、售電業或甲方營運相關而自動成為乙方義務。

## 第二條 專案目標

本專案目標為：

1. 了解並收斂甲方準備實際經營之售電事業定位及營運假設。
2. 將甲方確認之商業模式轉化為依主管機關現行法令、規定及申請要求可供審查之申請架構。
3. 完成核心申請文件及預估財務內容之撰寫、整合與一致性檢查。
4. 辦理正式送件，協助處理審查意見、修正及補件，推進本次申請程序。

## 第三條 第 1 階段 申照建置

第 1 階段適用於甲方已確定申請售電業、具備基本事業方向，且能提供並確認主要營運事實及假設之情形。乙方之角色為訪談、盤點、收斂、整合及撰寫。涉及甲方營運、電源、客戶及財務等資訊，乙方原則上負責盤點、收斂與一致性檢視，並於整合資訊後撰寫申請文件；相關事實、數據、假設及最終決策仍由甲方提供或確認。

### 一 專案啟動與資料盤點

1. 召開專案啟動會議，確認聯絡窗口、工作方式及資料提供安排。
2. 訪談甲方，盤點申請主體、甲方已確認之事業方向、既有準備及預定營運時程。
3. 整理公司、組織、人力、電源、售電對象、交易安排、系統及財務會計等現況資料。
4. 建立資料需求清單及缺口追蹤事項。

### 二 營運假設與申請架構整理

1. 盤點及整理甲方提供並確認之售電事業定位、既定營運方向、營運估算及相關試算；乙方不在本階段代甲方重新作成重大商業模式決策或自行建立商業收益、成本估算。
2. 盤點及整理甲方提供之預計或實際供電電廠、電源規劃、預估購電容量及購電量等事實，進行一致性檢視並轉化為申請內容。
3. 盤點及整理甲方提供之預計或實際售電對象、用戶規劃、預估售電量、銷售及收費模式等事實，進行一致性檢視並轉化為申請內容。
4. 盤點及整理甲方提供或確認之組織、人力、作業流程、風險及實際預計營運規則。
5. 將上述內容整合為《售電事業營運藍圖》或功能相同之成果。

### 三 核心申請文件

1. 依甲方確認之營運規劃撰寫及整合售電計畫書。
2. 依甲方預定實際營運方式撰寫及整合營業規章。
3. 依主管機關現行法令、規定及申請要求，整理其他必要核心申請資料。
4. 核對各文件中之公司定位、電源、售電對象、組織、人力、財務及營運規則是否一致。

### 四 預估財務資料

1. 說明售電業常見收入、購電成本、營運費用、人力及其他主要項目，以及申請資料所需格式、資訊與主管機關通常期待理解之內容。
2. 盤點、收斂及檢視甲方提供或確認之能源交易與財務基礎數據及假設。
3. 依申請需要及甲方提供或確認之資料，協助整理、編製及整合預估損益、資產負債、現金流、財務分析及敏感性分析等內容。
4. 檢查預估財務資料與售電計畫書及營運規劃之一致性。

前項工作不構成會計、審計、簽證、稅務或財務結果保證；乙方不代替甲方自行決定營運收益、成本、集團成本或最終財務數值，甲方仍應就其資料、假設、數值及採用結果負責。

## 第四條 第 2 階段 正式申請及審查支援

第 1 階段完成後，乙方依甲方確認之申請內容進入第 2 階段，辦理：

1. 依主管機關現行方式整理正式送件資料並辦理或協助辦理送件。
2. 與申請窗口進行必要之程序聯繫及進度追蹤。
3. 整理並解析主管機關審查意見，向甲方說明需由甲方決定或提供之事項。
4. 依甲方確認之資料及決策準備回覆內容，修正申請文件並辦理補件。
5. 就同一申請主體、已確認商業模式及原申請架構內之事項，提供合理範圍之再次修正與補件支援。
6. 持續推進本次申請，至主管機關申請程序完成，或依本契約暫停或終止。

依法令或主管機關要求須由甲方、其代表人、內部人員或第三方專業人士親自辦理、簽章、用印、認證或提出之事項，由相關主體完成，乙方提供合理之文件及程序協助。

## 第五條 交付成果

### 第 0 階段成果 選用時適用

1. 《前期事業規劃與決策建議》或功能相同之正式成果。
2. 重要方案或選項之比較分析。
3. 主要決策事項及建議。
4. Review & Decision 會議及成果說明。

### 第 1 階段成果

1. 資料需求及缺口清單。
2. 訪談及重要營運假設整理。
3. 《售電事業營運藍圖》或功能相同之成果。
4. 售電計畫書第一版完整稿。
5. 營業規章第一版完整稿。
6. 預估財務資料。
7. 依主管機關現行法令、規定及申請要求所需之其他核心申請文件或資料架構。
8. 文件間一致性檢查結果及待甲方確認事項。

### 第 2 階段成果

2. 主管機關審查意見整理及回覆建議。

4. 重要申請進度及程序結果紀錄。

交付成果之形式得依申請要求、文件性質及雙方工作安排，以電子檔、可編輯文件、申請系統資料、電子郵件或其他合理方式提供。

## 第六條 財務資料責任分工

### 一 乙方負責事項

1. 提供售電業營運經驗，說明常見財務項目、申請資料格式及主管機關通常期待理解之內容。
2. 盤點、收斂及檢視甲方提供或確認之能源交易相關假設。
3. 依甲方提供或確認之數據及假設，協助整理、編製及整合預估財務內容。
4. 檢查財務內容與售電計畫書及營運規劃的一致性。

### 二 甲方負責事項

1. 提供並確認公司或集團人員成本、內部管理成本、系統成本、既有資產、融資成本、會計處理、稅務、內部費用分攤及其他僅甲方掌握之財務會計資訊。
2. 提供並確認預定交易條件、電源與售電量、收入與成本等商業假設。
3. 對其提供及選擇採用之資料與假設的真實性、完整性、正確性及最終採用負責。
4. 涉及會計、稅務、簽證、審計或其他法定專業判斷時，自行委任適格專業人士。

## 第六條之一 會議與執行方式

1. 第 0 階段及第 1 階段原則包含 Kick-off、Workshop 及 Review & Decision 三類正式會議節點。Workshop 得依專案實際需要及利害關係人分工安排一場或數場；實際場次由乙方依完成本階段工作之合理需要安排。
2. 第 0 階段之會議功能如下：
   - **Kick-off**：確認專案目標、關鍵決策者及利害關係人，並辨識待作成之重大事業決策與限制。
   - **Workshop**：視需要邀集不同內部利害關係人，就法人、商業模式、電源、客戶、營運、組織及財務等需決策事項進行討論，由乙方提出選項、不同觀點及比較分析。
   - **Review & Decision**：說明分析與規劃成果、呈現需決策事項及建議，供甲方管理層決策，並確認是否及如何進入標準完整申照專案。
3. 第 1 階段之會議功能如下：
   - **Kick-off**：確認專案 owner 或主要窗口、申請主體，以及財務、法務、營運等資料窗口，並說明申辦流程、資料需求及分工。
   - **Workshop**：針對申請所需關鍵資訊與規則進行說明及取得資料；包括向財務人員說明財務預估資料之原則與格式、向法務或營運人員說明營業規章與待確認事項，以及向能源或業務窗口確認電源、售電對象及營運事實。Workshop 得依實際需要安排一場或數場。
   - **Review & Decision**：說明已完成成果及尚待甲方確認事項，確認營運藍圖、售電計畫書、營業規章、財務內容及其他核心申請文件；甲方完成必要確認後進入第 2 階段正式送件。
4. 因甲方之決策、重大變更或其他非屬原工作範圍之需求而要求增加之會議或重作，不包含於上述標準服務，應依第十一條變更管理辦理。
5. 本服務原則以遠端方式執行，包括視訊會議、電話、電子郵件、線上文件協作或其他合理電子方式。因甲方要求或案件實際需要安排乙方前往指定地點提供現場服務時，必要之大眾運輸、計程車、停車、住宿及其他合理差旅支出，由甲方依實際發生負擔或實報實銷；不另行收取固定出席費或現場服務費。現場會議如係因甲方決策、重大變更或範圍外需求所生，仍依第十一條辦理。

1. 甲方應指定具適當權限之單一主要窗口，負責提供資料、傳達決策、確認內容及協調內部作業。
2. 甲方應於乙方提出之合理期限內提供完整、正確、合法、最新且盡量符合未來真實營運之文件及資訊。
3. 甲方應確認申請主體、商業模式、電源、售電對象、組織、人力、財務與交易假設及最終申請內容。
4. 甲方應取得乙方執行本服務所需之內部批准，以及第三方資料、機密資訊或受保密義務拘束資訊之合法使用及揭露授權。
5. 甲方應依需要完成簽章、用印、付款、委任、授權及必要決策，並將主管機關或其他相關主體直接通知甲方之重要資訊及時提供乙方。

甲方未履行前項義務所造成之延遲，服務時程應相應順延；乙方之暫停或順延不影響已完成工作或已到期款項之請求。

## 第八條 文件審閱及送件把關

1. 乙方得對甲方或第三方提供之資料與草稿進行合理審閱及一致性檢查。
2. 如內容有明顯缺漏、錯誤、前後矛盾、不符合整體申請架構或與甲方確認之實際營運規劃不一致，乙方得要求補正。
3. 在甲方未完成必要確認、補正、簽章或決策前，乙方得依專業判斷暫緩送件。
4. 乙方之審閱及把關不免除甲方對其資料、決策及申請內容之最終責任，也不構成法律、會計、稅務、工程或其他法定專業意見。

## 第九條 階段完成及十個工作日確認

1. 第 0 階段完成係指乙方已完成並交付《前期事業規劃與決策建議》或功能相同之正式成果，並已完成 Review & Decision 會議。第 0 階段之目的為提供足供甲方作成後續事業及申照決策之分析、選項、比較與建議；甲方是否決定申請、決定不申請、採用乙方建議之特定方案或作成任何特定商業決策，均非第 0 階段完成之必要條件。
2. 第 1 階段完成係指乙方已依本工作範圍書完成第 1 階段約定成果，形成可進入正式主管機關申請程序的第一版完整申請架構，並交付甲方；甲方已確認，或依第三款視為完成確認。主管機關是否受理、接受或核准，不屬第 1 階段完成之要件。
3. 甲方應於收到乙方各階段交付成果之日起十個工作日內完成確認或提出具體且合理之修正意見；逾期未提出者，視為該階段交付成果已完成確認。第 0 階段之完成認定不因甲方尚未作成特定決策而延後。
4. 甲方提出之修正意見應以原服務範圍及已確認之資料、假設與方向為基礎。甲方後續變更已確認事項而造成重大重作者，依第十一條變更管理辦理。
5. 第 2 階段之主管機關申請程序完成，係指乙方已完成本工作範圍書約定之送件、審查意見處理及補件支援，且主管機關已就本次申請作成核准、駁回、不予受理、退件或其他足以終結本次申請程序之正式處置。甲方主動中止、本契約提前終止，或程序終結係因可歸責於乙方之重大違約所造成時，不視為第三筆正常付款節點；應依本契約之重大違約、改善、責任、終止及結算條款辦理。

## 第十一條 變更管理及追加服務

1. 甲方提出原範圍外需求、要求乙方重作原非乙方負責之內容，或變更已確認之商業模式、資料或決策而造成重大重作時，乙方應說明影響。

## 第十二條 法規及主管機關要求變動

1. 一般合理程度之表單、格式或補充要求調整，乙方於原範圍內合理處理。

## 第十四條 第 0 階段 前期事業規劃 選配

1. 第 0 階段適用於甲方尚未完全確定是否或如何申請售電業、尚未決定申請牌照之法人主體，或售電事業模式仍需管理層作成重大決策之情形。乙方之角色為提出方案與不同觀點、進行比較分析及協助決策，協助甲方決定要建立何種售電事業。
2. 第 0 階段主要工作包括：
   - 比較不同營運模式，協助評估預期收益、成本及商業可行性，供管理層選擇適合之模式。
   - 整理候選供電案場或電源條件，比較及分析供電策略。
   - 整理及釐清預計售電對象、目標客群或售電方向。
   - 依預計營運模式，協助設計初步營運規劃及角色安排。
   - 協助進行商業可行性及模型選擇之分析。
3. 第 0 階段之成果定位為《前期事業規劃與決策建議》或功能相同之正式成果，作為甲方管理層決策及評估是否、如何進入標準完整申照專案之依據。
4. 本模組費用為 NT$150,000 未稅，不包含在標準完整申照專案 NT$450,000 未稅內；其啟動、請款及付款方式依第五條及本契約辦理。
5. 乙方應以合理專業注意義務及合理效率推進第 0 階段，不承諾固定完成天數。因甲方資料、決策、內部窗口、利害關係人、會議安排、第三人或其他非可歸責乙方之因素造成延遲者，時程相應順延。
6. 第 0 階段之完成、成果確認、暫緩及提前終止，分別依第九條及本契約之暫緩與終止條款辦理。
7. 甲方未選用第 0 階段時，即確認其已具備足以啟動標準完整申照專案之基本事業方向。標準完整申照專案不包含重新比較重大事業模式、法人主體之重大策略比較、建立全新電源策略、建立全新售電市場策略、替甲方重新設計完整商業模式，或替管理層進行前期事業可行性決策。
8. 未選用第 0 階段時，乙方於第 1 階段仍得提問、檢視明顯矛盾、盤點、收斂、整合及檢查一致性；前述工作不因此視為已包含第 0 階段。
