# 新版售電業申照服務文件來源對照

## 使用原則

本對照表記錄新版報價單、SOW 與正式契約的設計依據。來源僅用來抽取結構、責任配置與資訊顆粒度，不作逐字複製，也不將來源個案的客戶、案場、售電對象、價格或財務數字帶入新文件。涉及法規之內容一律改採「依主管機關現行法令、規定及申請要求辦理」等穩健表述。

## 來源順位與用途

| 順位 | 來源 | 沿用的思想 | 明確不沿用 |
| --- | --- | --- | --- |
| 1 | 東元正式服務契約 | 契約性質、獨立承攬角色、甲乙方權責、SOW 邊界、付款異議、暫停、非結果保證、責任限制、保密、智慧財產、通知、文件效力及完整合意 | 年度契約、自動續約、轉供級距、區處數量、申請次數、年度費、個案內容，以及免經同意使用客戶名稱或標誌的設計 |
| 2 | 東元 SOW | 文件層級、服務內容與限制、不包含事項、甲方配合、資料錯誤或延遲、完成定義、甲方變更造成重作及追加服務 | 轉供計畫書、轉供契約、餘電躉售、換文修約、履約保證金、轉供次數、區處級距及年度營運內容 |
| 3 | 東元價格附件 | 未稅表述、第三方費用與差旅另計、追加服務、請款異議、已發生費用不因第三方事件任意減免，以及書面折讓或例外安排 | 舊年度價格、年度方案、工時費率與服務級距 |
| 4 | 瑞光售電業申照契約 | 申照流程、公司資料、供電來源、售電對象、營業規章、售電計畫書、正式申請、主管機關往返與資料清單的工作 precedent | 舊價格、舊付款、不得單方終止、舊法規門檻、舊公司設立資訊及任何客戶身份資料 |
| 5 | 育成營業規章 | 營業規章需涵蓋的實際營運規則類型，例如服務申請、契約管理、計費、供電、計量與用戶資料處理 | 來源公司的規章文字、期間、費率、罰則、交易對象及其他個案設定 |
| 6 | 育成售電計畫書 | 售電計畫所需資訊顆粒度，包括公司定位、購電來源、容量與電量、售電對象、用戶數、收入、成本、人力、損益、資產負債、現金流、財務分析及敏感性分析 | 來源公司的名稱、關係企業、案場、客戶、電價、容量、財務數字、年度及商業假設 |

## 新文件主要條文來源

| 新文件主題 | 主要來源 | 本案設計方式 |
| --- | --- | --- |
| 服務定位與角色分工 | 東元契約 | 改寫為申照輔導與申請服務；甲方保有商業決策及申請內容最終確認權，乙方負責專業整理、撰寫、整合與程序推進 |
| 申照工作內容 | 瑞光契約及育成成果 | 將公司、電源、售電對象、營運規則及財務內容整合為兩階段服務，不沿用舊個案內容 |
| 第一階段交付成果 | 瑞光契約、育成成果及本案商業規則 | 新設《售電事業營運藍圖》、售電計畫書、營業規章、預估財務資料及其他核心申請文件的完整交付組合 |
| 財務成果顆粒度 | 育成售電計畫書 | 要求收入、成本、營運費用、人力、損益、資產負債、現金流、財務分析與敏感性分析可依申請需求建立；數值及會計判斷由甲方提供確認 |
| 工作範圍邊界 | 東元 SOW 與契約 | 未列入工作不自動納入；甲方變更已確認事項或要求重大重作時啟動變更管理 |
| 甲方資料與配合義務 | 東元契約、東元 SOW 及瑞光契約 | 要求資料完整、正確、合法及貼近未來真實營運；甲方負責決策、確認、簽章與授權 |
| 文件審閱與送件把關 | 東元 SOW 邊界設計及本案新規則 | 新設乙方審閱、一致性檢查、要求補正及判斷是否適宜送件的專業權限 |
| 第一階段完成與十日確認 | 東元契約、東元 SOW 及本案新規則 | 以交付可進入申請程序的第一版完整架構為基礎，加上十個工作日確認或視為確認機制 |
| 正常價格與付款 | 本案商業規則 | 全新設計為 NT$450,000 未稅及 100,000／200,000／150,000 三節點；不沿用任何來源價格 |
| 前期規劃選配 | 本案商業規則 | 全新設計為標準專案前的 NT$150,000 未稅獨立模組 |
| 第 0 階段結算及第一筆請款分流 | Zac 本案商業規則 | 第 0 階段啟動全額請款 150,000；完成前終止僅守 150,000；完成後不進標準專案或暫緩逾三個月另收 112,500；第 1 階段啟動後回歸 275,000／375,000 機制。選用第 0 階段時，標準專案第一筆 100,000 延至第 1 階段啟動請款 |
| 第 0／第 1 階段責任邊界 | Zac 本輪商業規則 | 新設第 0 階段「提出方案、比較、challenge、協助決策」及第 1 階段「訪談、盤點、收斂、整合、撰寫」之邊界；甲方仍提供或確認營運事實、數據、假設及最終決策 |
| 模組式選擇 | Zac 本輪商業規則 | 標準完整申照專案固定存在；第 0 階段為其前置選配而非替代方案，簽署版本依客戶接受結果勾選 |
| 三節點會議模型 | Zac 本輪商業規則 | 第 0 及第 1 階段均採 Kick-off、Workshop、Review & Decision；Workshop 由乙方依完成階段工作之合理需要安排一場或數場，不形成無限會議承諾 |
| 遠端執行原則 | Zac 本輪商業規則 | 新設服務原則遠端執行；現場出席不另設固定出席或工時費 |
| 現場服務及差旅 | 東元價格附件及 Zac 本輪商業規則 | 參考指定地點服務、交通、差旅及實報實銷之既有設計思想，改寫為因甲方要求或案件需要出席現場時，必要合理差旅由甲方負擔；範圍外會議仍走變更管理 |
| 暫緩與提前終止 | 東元契約的改善與終止結構及本案商業規則 | 全新設計暫緩抵充、第一階段 275,000 及第二階段 375,000 結算邏輯，並保留乙方重大違約例外 |
| 非結果保證 | 東元契約及東元 SOW | 明確承諾完成約定程序，但不保證核照、時程、不補件或特定商業模式獲接受 |
| 法規變更 | 東元契約、瑞光契約及本案新規則 | 一般調整納入原範圍；重大變動得暫停、重估、追加報價或終止結算，避免無限範圍 |
| 保密 | 東元契約及瑞光契約 | 涵蓋公司、電源、售電客戶、NDA 及財務資料；公開客戶名稱或標誌須事前書面同意 |
| 智慧財產權 | 東元契約 | 區分甲方原始資料、乙方既有方法與通用工具，以及甲方於付清款項後對專案成果的內部與申請使用權 |
| 責任限制 | 東元契約 | 採實際支付服務費為責任上限、排除間接損害，並保留故意、重大過失及依法不得限制之責任 |
| 後續營運排除 | 本案商業規則 | 明定取得執照後之實際營運、電能轉供及其他營運支援不在本案內，需另案議定 |

## 本案全新設計

下列內容不是舊文件換名，而是依本案商業規則重新設計：

- 「再生能源售電業申照輔導暨申請服務」的完整產品定位。
- 兩階段工作流程及《售電事業營運藍圖》成果。
- NT$450,000 標準價格與三筆付款節點。
- NT$150,000 前期售電事業規劃顧問選配模組。
- 第 0 階段完成前與完成後的暫緩、提前終止結算，以及 NT$112,500 之適用界線。
- 選用第 0 階段時，標準專案第一筆 NT$100,000 延至第 1 階段啟動請款之分流。
- 第 0 階段與第 1 階段的責任邊界及模組式選擇。
- Kick-off、Workshop、Review & Decision 三節點會議模型。
- 原則遠端執行，以及現場必要差旅實報實銷的工作方式。
- 所有正常請款均採完整發票及請款文件送達次日起十個工作日付款，且專案啟動不以第一筆款項實際入帳為條件。
- 十個工作日確認機制。
- 暫緩款抵充第二筆費用的設計。
- 第一階段與第二階段的提前終止結算。
- 甲方財務資料責任及乙方非會計、簽證或審計角色。
- 申請文件把關權及重大變更的追加服務機制。
