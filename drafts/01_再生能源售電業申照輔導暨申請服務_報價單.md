## 一 服務目的

優選股份有限公司將協助客戶釐清擬經營之再生能源售電事業，透過訪談、資料盤點及營運假設整理，將客戶的商業模式轉化為可供主管機關審查的申請架構，並完成核心申請文件、正式送件、審查意見處理及補件支援。

本服務以客戶未來實際營運規劃為基礎。客戶仍須參與並確認其事業定位、組織與人力、電源與售電策略、交易假設、財務會計資料及最終申請內容。

## 二 服務模組與工作階段

### 標準完整申照專案 核心專案

標準完整申照專案固定包含第 1 階段及第 2 階段，總價為 NT$450,000 未稅。

#### 第 1 階段 申照建置

- 專案啟動、需求訪談及申請策略整理。
- 依客戶提供及確認之既定事業方向，盤點申請主體、營運模式及資料缺口。
- 盤點、收斂並檢查客戶提供之電源、售電對象、組織角色及營運事實的一致性。
- 售電事業營運架構及《售電事業營運藍圖》或功能相同成果。
- 售電計畫書、營業規章及其他必要核心申請文件之撰寫與整合。
- 說明申照常見收入與成本項目、資料格式及主管機關希望理解的內容，並就客戶提供及確認之基礎數據、假設與最終數值進行盤點、收斂、一致性檢查及文件整合。
- 申請文件間之一致性檢查。
- 形成可進入正式主管機關申請程序的第一版完整申請架構，交付客戶確認。

第 1 階段的功能是把客戶已決定的售電事業轉化為正式申請。涉及客戶營運、電源、售電對象及財務之事實、數據、假設與最終決策，仍由客戶提供或確認。

#### 第 2 階段 正式申請及審查支援

- 正式主管機關送件及申請窗口往來。
- 審查意見整理、解析及回覆內容準備。
- 申請文件修正及補件。
- 合理範圍內之再次修正與補件支援。
- 申請進度追蹤及程序推進。
- 完成本次約定之主管機關申請程序。

### 第 0 階段 前期事業規劃 選配

本模組適用於尚未完全確定是否或如何申請售電業、尚未決定申請牌照之法人主體，或仍需由管理層作成重大事業決策的客戶。優選股份有限公司將提出方案與不同觀點、進行比較分析並協助決策，協助客戶就下列事項作成選擇：

- 比較營運模式，評估預期收益、成本與商業可行性。
- 整理候選供電案場或電源條件，比較供電策略。
- 釐清預計售電對象、目標客群及售電方向。
- 依預計營運模式設計初步營運規劃及角色安排。
- 進行商業可行性及模型選擇分析。

主要成果為「前期事業規劃與決策建議」，協助客戶決定要建立何種售電事業，以及是否與如何進入標準完整申照專案。

## 三 主要成果

1. 售電事業營運藍圖或功能相同之營運規劃成果。
2. 售電計畫書。
3. 營業規章。
4. 預估財務資料及其與營運規劃之一致性整合。
5. 依主管機關現行法令、規定及申請要求所需之其他核心申請資料。
6. 正式送件、審查意見處理及補件紀錄。

選用第 0 階段時，另提供《前期事業規劃與決策建議》或功能相同之正式成果、重要方案與選項之比較分析、主要決策事項及建議，並完成 Review & Decision 會議。

## 四 專案費用及付款節點

### 第 0 階段 前期事業規劃 選配

- 費用為 **NT$150,000 未稅**，於第 0 階段正式啟動時全額成為可請款款項。
- 第 0 階段正式啟動不以優選股份有限公司實際收到前述款項為條件。
- 完成節點為交付《前期事業規劃與決策建議》或功能相同之正式成果，並完成 Review & Decision 會議。

### 標準完整申照專案 固定核心專案

標準完整申照專案總價為 **NT$450,000 未稅**。

| 款次 | 金額 未稅 | 付款節點 |
| --- | ---: | --- |
| 第一筆 | NT$100,000 | 標準完整申照專案正式啟動 |
| 第二筆 | NT$200,000 | 第 1 階段完成 |
| 第三筆 | NT$150,000 | 主管機關申請程序完成 |

第 1 階段完成係指優選股份有限公司已完成並交付可進入正式主管機關申請程序的第一版完整申請架構，且客戶已依 SOW 及正式服務契約完成確認；此一節點不表示主管機關已受理、接受或核准申請。

- 未選用第 0 階段時，標準完整申照專案於契約成立日或雙方約定之啟動日正式啟動，第一筆 NT$100,000 同時成為可請款款項。
- 選用第 0 階段時，契約成立後先啟動第 0 階段；此時僅請款第 0 階段 NT$150,000。第 0 階段完成且客戶進入第 1 階段時，標準完整申照專案正式啟動，第一筆 NT$100,000 始成為可請款款項。
- 各階段啟動均不以優選股份有限公司實際收到對應款項為條件。各付款節點成立後，優選股份有限公司得開立發票及完整請款文件；客戶應於收到完整發票及請款文件之次日起十個工作日內付款。
- 正常完成之付款順序：未選用第 0 階段者為 NT$100,000、NT$200,000、NT$150,000，合計 NT$450,000 未稅；選用第 0 階段者為 NT$150,000、NT$100,000、NT$200,000、NT$150,000，合計 NT$600,000 未稅。

## 七 會議與執行方式

- 第 0 階段及第 1 階段原則包含 Kick-off、Workshop 及 Review & Decision 三類正式會議節點。Workshop 得依專案實際需要及利害關係人分工安排一場或數場；實際場次由優選股份有限公司依完成本階段工作之合理需要安排。
- 甲方之決策、重大變更或其他非屬原工作範圍之需求而要求增加之會議或重作，不包含於上述標準服務。
- 本服務原則以遠端方式執行，包括視訊會議、電話、電子郵件、線上文件協作及其他合理電子方式。
- 因客戶要求或案件實際需要安排現場服務時，必要之大眾運輸、計程車、停車、住宿及其他合理差旅支出，由客戶依實際發生負擔或實報實銷。本報價未另設固定出席費或現場服務費；如現場會議係因客戶決策、重大變更或範圍外需求增加，仍依追加服務機制辦理。
