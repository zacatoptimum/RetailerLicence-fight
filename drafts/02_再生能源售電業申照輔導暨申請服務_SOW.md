# 售電業申照輔導暨申請服務

# 服務工作範圍書

## 前言

本服務工作範圍書（SOW）為「售電業申照輔導暨申請服務契約」（以下稱「本契約」）之附件，與本契約具有同等效力。本服務工作範圍書未定義之名詞，依本契約之定義。

## 一、文件性質與本案選用服務

1. 本服務工作範圍書為本案服務範圍之唯一詳細依據，用以界定本案選用之服務模組、各階段工作、交付成果、完成標準、雙方工作與資料分工、會議與執行方式、不包含事項及變更管理。
2. 本案選用服務模組如下：

   - ☐ 第 0 階段｜前期事業規劃（選配）
   - ☒ 第 1 階段＋第 2 階段｜標準完整申照專案

3. 第 0 階段為標準完整申照專案之前置選配，並非標準完整申照專案之替代方案。標準完整申照專案固定包含第 1 階段及第 2 階段。
4. 第 0 階段是否選用，以本服務工作範圍書之勾選結果為準；未勾選者，視為甲方未選用第 0 階段。
5. 甲方未選用第 0 階段時，即確認其已具備足以啟動第 1 階段之基本事業方向。第 1 階段不包含重新比較重大事業模式、就申請牌照之法人主體進行重大策略比較、建立全新電源策略或售電市場策略、重新設計完整商業模式，或代替甲方管理層進行前期事業可行性決策。乙方於第 1 階段仍得提問、檢視明顯矛盾、盤點、收斂、整合及檢查一致性，前述工作不因此視為已包含第 0 階段。
6. 本服務工作範圍書未列入之工作，不因與售電業申照、能源交易或甲方營運相關而自動成為乙方義務。

## 二、專案目標

1. 以甲方準備實際經營之售電事業為基礎，釐清、盤點並收斂申請所需之營運事實、資料及假設。
2. 將甲方已決定之事業方向及已確認之商業模式，轉化為依主管機關現行法令、規定及申請要求可供審查之申請架構。
3. 完成核心申請文件、預估財務內容及其他申請資料之撰寫、整合與一致性檢查。
4. 辦理正式送件，協助處理審查意見、文件修正及補件，並以合理專業注意義務及合理效率推進本次申請程序。

## 三、第 0 階段｜前期事業規劃

本階段僅於甲方勾選第 0 階段時適用，適合申照方案、申請牌照之法人主體或售電事業模式仍需由甲方管理層作成重大決策之情形。本階段之目的，是協助甲方決定要建立何種售電事業；乙方之角色為提供諮詢、比較分析、提出不同觀點及協助決策。

本階段工作包括：

1. 比較不同營運模式，協助評估預期收益、成本及商業可行性，並整理各方案之主要差異及影響。
2. 就申請牌照之法人主體及相關事業安排，整理可行選項及應由甲方管理層決定之事項；涉及法律、會計或稅務之專業判斷，由甲方另行委任適格專業人士。
3. 整理候選電源、供電條件及供電策略，協助比較其與甲方預定營運模式之適配性。
4. 釐清預計售電對象、目標客群、售電方向及主要市場假設。
5. 依預計營運模式，協助規劃初步營運方式、組織角色及主要決策事項。
6. 整合分析、選項、比較及建議，形成足供甲方作成後續事業及申照決策之正式成果。

本階段交付成果及完成標準依第六節辦理；會議安排依第九節辦理。

## 四、第 1 階段｜申請資料準備

本階段適用於甲方已確定申請售電業、具備基本事業方向，且能提供並確認主要營運事實及假設之情形。本階段之功能，是將甲方已決定之售電事業轉化為可正式送件之完整申請架構。乙方負責訪談、盤點、收斂、整合、撰寫及一致性檢查；涉及甲方營運、電源、售電對象、組織、人力及財務之事實、數據、假設與最終決策，仍由甲方提供或確認。

### （一）專案啟始與資料盤點

1. 確認主要聯絡窗口、內部資料窗口、執行方式及資料提供安排。
2. 進行需求訪談，盤點申請主體、甲方已確認之事業方向、營運模式、既有準備及預定營運安排。
3. 盤點公司、組織、人力、電源、售電對象、交易安排、系統及財務會計等申請所需資料。
4. 建立資料需求及缺口清單，追蹤甲方應提供、補充或確認之事項。

### （二）營運資訊及申請架構整理

1. 盤點並整理甲方提供及確認之商業模式、營運事實、營運估算與相關試算；乙方不在本階段代替甲方重新作成重大商業決策，亦不自行產生甲方之營運收入、成本或其他公司內部數值。
2. 盤點並整理甲方提供之預計或實際供電電廠、電源規劃、購電容量、購電量及其他電源事實，進行一致性檢查並轉化為申請內容。
3. 盤點並整理甲方提供之預計或實際售電對象、用戶規劃、售電量、銷售與收費安排及其他售電事實，進行一致性檢查並轉化為申請內容。
4. 盤點並整理甲方提供或確認之組織、人力、作業流程、系統、風險及預計營運規則。
5. 將前述資訊整合為《售電事業營運藍圖》或功能相同之營運規劃成果。

### （三）核心申請文件撰寫與整合

1. 依甲方確認之營運規劃，撰寫及整合《售電計畫書》。
2. 依甲方預定之實際營運方式，撰寫及整合《營業規章》。
3. 依主管機關現行法令、規定及申請要求，整理其他必要之核心申請文件或資料架構。
4. 依第八節之分工，整理及整合預估財務內容。
5. 檢查各申請文件中之申請主體、事業定位、電源、售電對象、組織、人力、財務及營運規則是否一致。
6. 整理尚待甲方確認或補正之事項，並在甲方完成必要確認後，形成可進入正式主管機關申請程序之完整申請架構。

本階段交付成果及完成標準依第六節辦理；會議安排依第九節辦理。

## 五、第 2 階段｜正式申請及審查支援

第 1 階段完成後，乙方依甲方確認之申請內容進入第 2 階段，辦理下列工作：

1. 依主管機關現行申請方式整理正式送件資料，並辦理或協助辦理送件。
2. 與申請窗口進行必要之程序聯繫及申請進度追蹤。
3. 整理及解析主管機關審查意見，並向甲方說明應由甲方決定、提供或確認之事項。
4. 依甲方提供及確認之資料與決策準備回覆內容，於原申請主體、已確認商業模式及原申請架構內，進行合理範圍之文件修正及補件支援。
5. 配合本次申請之合理需要，再次修正申請文件及補充說明。
6. 以合理專業注意義務及合理效率推進本次申請程序，至收到主管機關之申辦完成通知函，或其他足以終結本次申請程序之正式通知或處置。

依法令或主管機關要求須由甲方、甲方代表人、甲方內部人員或第三方專業人士親自辦理、簽章、用印、認證或提出之事項，由相關主體完成；乙方提供合理之文件及程序協助。

## 六、交付成果及完成標準

### （一）第 0 階段

1. 交付成果包括：
   1. 《前期事業規劃與決策建議》或功能相同之正式成果。
   2. 重要方案或選項之比較分析。
   3. 主要待決事項及建議。
   4. 匯報會議之成果說明。
2. 第 0 階段完成，係指乙方已交付前款成果，並完成匯報會議。
3. 第 0 階段旨在提供足供甲方作成後續事業及申照決策之分析、選項、比較與建議。甲方是否決定申請、決定不申請、採用特定方案或作成特定商業決策，均非本階段完成之必要條件。
4. 甲方應於收到本階段交付成果之日起十個工作日內完成確認，或提出具體且合理之修正意見；逾期未提出者，視為本階段交付成果已完成確認。甲方不得以尚未作成特定決策為由延後完成認定。

### （二）第 1 階段

1. 交付成果包括：
   1. 資料需求及缺口清單。
   2. 訪談及重要營運事實、資料與假設之整理。
   3. 《售電事業營運藍圖》或功能相同之營運規劃成果。
   4. 《售電計畫書》完整申請稿。
   5. 《營業規章》完整申請稿。
   6. 依甲方提供及確認之資料所整理之預估財務內容。
   7. 依主管機關現行法令、規定及申請要求所需之其他核心申請文件或資料架構。
   8. 文件間一致性檢查結果及待甲方確認事項。
2. 第 1 階段完成，係指乙方已依本服務工作範圍書完成約定工作，形成可進入正式主管機關申請程序之完整申請架構，並交付甲方確認。
3. 甲方應於收到本階段交付成果之日起十個工作日內完成確認，或提出具體且合理之修正意見；逾期未提出者，視為本階段交付成果已完成確認。
4. 主管機關是否受理、接受或核准，不屬第 1 階段完成之要件。

### （三）第 2 階段

1. 交付成果包括：
   1. 正式送件版本及送件資料清單。
   2. 主管機關審查意見之整理、解析及回覆建議。
   3. 依約完成之修正版、補件文件及必要說明。
   4. 重要申請進度及程序結果紀錄。
2. 主管機關申請程序完成，係指乙方已完成本服務工作範圍書約定之送件、審查意見處理及補件支援，並已收到主管機關之申辦完成通知函，或其他足以終結本次申請程序之正式通知或處置。
3. 如本次申請因甲方主動中止、本契約提前終止，或因可歸責於乙方之重大違約而終結，其法律效果、付款及結算依本契約辦理，不逕視為第三筆正常付款節點成立。

交付成果得依申請要求、文件性質及雙方工作安排，以電子檔、可編輯文件、主管機關申請系統資料、電子郵件或其他合理方式提供。

## 七、甲乙雙方資料與工作分工

### （一）甲方負責事項

1. 指定具適當權限之主要聯絡窗口，負責資料提供、決策傳達、內容確認及內部協調。
2. 於乙方提出之合理期限內，提供完整、正確、合法、最新且盡量符合未來真實營運之文件、資訊、數據及商業假設。
3. 提供並確認商業模式、營運事實、電源、售電對象、組織、人力、成本、財務數據、財務假設、會計與稅務資訊及最終申請內容。
4. 取得第三方資料、機密資訊或受保密義務拘束資訊供乙方使用或向主管機關提出所需之同意與授權。
5. 依需要完成確認、補正、簽章、用印、付款、委任、授權及其他必要決策。
6. 將主管機關或其他相關主體直接通知甲方之重要資訊及時提供乙方。
7. 對甲方提供或確認之資料、數據、假設、指示、決策及簽署文件之真實性、完整性、正確性、合法性及最終採用負責。

### （二）乙方負責事項

1. 依本服務工作範圍書，以合理專業注意義務及合理效率提供服務。
2. 依甲方提供及確認之資料，進行訪談、盤點、收斂、整合、撰寫及文件間一致性檢查。
3. 發現資料或文件有明顯缺漏、錯誤、矛盾、不符合申請架構或與已確認營運規劃不一致時，通知甲方補正、說明或確認。
4. 對甲方或第三方提供之資料與草稿進行合理審閱，並保有要求補正及判斷是否適宜送件之專業權限。
5. 在甲方未完成必要確認、補正、簽章或決策前，得暫緩相關工作或送件；所生時程及法律效果依本契約辦理。

乙方之審閱、一致性檢查及送件把關，不免除甲方對其資料、決策及申請內容之最終責任，亦不構成法律、會計、稅務、工程或其他依法應由特定資格人士提供之專業意見。

## 八、財務資料分工

### （一）乙方負責事項

1. 提供售電業營運經驗，說明常見收入、購電成本、營運費用、人力及其他主要財務項目。
2. 說明申請資料所需之格式、資訊及主管機關通常期待理解之內容。
3. 盤點、收斂及檢視甲方提供或確認之能源交易與財務基礎數據及假設。
4. 依申請需要及甲方提供或確認之資料，協助整理、編製及整合預估損益、資產負債、現金流、財務分析及敏感性分析等內容。
5. 檢查預估財務內容與《售電計畫書》及營運規劃之一致性。

### （二）甲方負責事項

1. 提供並確認公司或集團人員成本、內部管理成本、系統成本、既有資產、融資成本、會計處理、稅務、內部費用分攤及其他僅甲方掌握之財務會計資訊。
2. 提供並確認預定交易條件、電源與售電量、收入、成本及其他商業或財務假設。
3. 對其提供或選擇採用之資料、數據、假設與最終數值之真實性、完整性、正確性及最終採用負責。
4. 涉及會計、稅務、簽證、審計或其他法定專業判斷時，自行委任適格專業人士。

乙方不代替甲方自行決定營運收入、成本、集團成本、會計處理或最終財務數值，亦不擔任甲方之會計師、財務簽證人、審計人或財務結果保證人。

## 九、會議與執行方式

1. 第 0 階段及第 1 階段原則均包含專案啟始會議、工作會議及匯報會議三類正式會議節點。
2. 專案啟始會議用於說明專案、確認關鍵窗口與利害關係人、確認資料需求及執行方式；第 0 階段另確認待作成之重大事業決策與限制，第 1 階段另確認申請主體及財務、法務、營運等資料窗口。
3. 工作會議依案件需要，與財務、法務、營運、能源、業務或其他相關人員進行資料盤點、規則說明、討論及確認。工作會議得依專案實際需要及利害關係人分工安排一場或數場，實際場次由乙方依完成該階段工作之合理需要安排，不構成不限次會議。
4. 第 0 階段之匯報會議用於說明《前期事業規劃與決策建議》、主要選項及待決事項；第 1 階段之匯報會議用於說明完整申請架構、核心申請文件及尚待甲方確認之事項。
5. 甲方之決策、重大變更或其他非屬原工作範圍之需求而要求增加之會議或重作，不包含於上述標準服務。
6. 本服務原則以遠端方式執行，包括視訊會議、電話、電子郵件、線上文件協作及其他合理電子方式。
7. 因甲方要求或案件實際需要，須由乙方前往指定地點提供現場服務時，必要之大眾運輸、計程車、停車、住宿及其他合理差旅支出，由甲方依實際發生負擔或實報實銷；本服務不另收取固定出席費、現場服務費或現場工時費。現場會議如係因甲方決策、重大變更或原工作範圍外需求所生，仍依第十一節辦理。

## 十、服務範圍限制及不包含事項

本服務不包含：

1. 代替甲方就商業模式、交易條件、電價、投資、融資、會計、稅務、組織或其他經營事項作成最終決定。
2. 律師、會計師、審計、簽證、工程、技師或其他依法應由特定資格人士提供之服務。
3. 甲方公司設立或變更登記本身、資金募集、融資文件、股東協議或內部治理文件；雙方另有書面約定者，不在此限。
4. 超出本次申照所需之客製研究、盡職調查、第三方查核、系統建置、資料庫建置或軟體開發。
