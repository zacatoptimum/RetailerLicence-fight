# 售電業申照輔導暨申請服務契約

立契約人：

甲方：【客戶完整名稱】（以下稱「甲方」）

乙方：優選股份有限公司（以下稱「乙方」）

甲方委託乙方提供售電業申照輔導暨申請服務。雙方同意，乙方應以甲方準備實際經營之售電事業及甲方確認之資料與決策為基礎，依雙方簽署之服務工作範圍書提供專業輔導、文件整合及申請程序支援，並約定如下。

## 第一條 定義

1. **服務工作範圍書**：指雙方簽署之「售電業申照輔導暨申請服務之服務工作範圍書」，為本契約之附件，並為雙方實際選用之服務、詳細工作範圍、交付成果、完成標準及工作分工之依據。
2. **本服務**：指乙方依本契約及服務工作範圍書，就服務工作範圍書中實際選用之服務模組提供之服務。
3. **第 0 階段**：指服務工作範圍書所定之「前期事業規劃」選配服務。
4. **標準完整申照專案**：指固定包含第 1 階段「申請資料準備」及第 2 階段「正式申請及審查支援」之服務。
5. **第 0 階段完成**：指乙方已依服務工作範圍書交付《前期事業規劃與決策建議》或功能相同之正式成果，並完成匯報會議；甲方是否決定申請、決定不申請、採用特定方案或作成特定商業決策，均非完成要件。
6. **第 1 階段完成**：指乙方已依服務工作範圍書完成第 1 階段約定工作，形成可進入正式主管機關申請程序之完整申請架構並交付甲方，且甲方已確認或依第七條視為完成確認。主管機關是否受理、接受或核准，不屬完成要件。
7. **主管機關申請程序完成**：指乙方已完成服務工作範圍書約定之送件、審查意見處理及補件支援，並已收到主管機關之申辦完成通知函，或其他足以終結本次申請程序之正式通知或處置。甲方主動中止、本契約提前終止，或程序終結係因可歸責於乙方之重大違約所造成時，不視為第三筆正常付款節點成立。
8. **工作日**：指中華民國政府行政機關之正常辦公日，不含星期六、星期日及依法放假日。
9. **主管機關**：指依法管轄本次售電業申請之機關；其名稱、權限及申請要求，依辦理時之現行法令、規定及申請要求為準。

## 第二條 契約性質與角色分工

1. 本契約為乙方提供專業顧問、文件整合及申請程序支援之契約。乙方得依專業判斷自主安排工作方法、執行順序、人員配置及作業時間。
2. 甲方為申請主體及未來售電事業之經營決策者，應就事業定位、商業模式、電源、售電對象、組織、人力、財務、資金、交易假設及最終申請內容作成決定並負責。
3. 乙方依甲方提供及確認之真實營運規劃、資料與決策提供服務，不負責替甲方虛構僅為通過審查之內容。
4. 除甲方另以書面明確授權外，乙方無權以甲方名義簽署文件、承諾商業條件、作成法律意思表示、收受款項或對第三人負擔義務。
5. 甲乙雙方間不因本契約成立僱傭、勞動派遣、合夥、共同經營、經銷、代理或其他類似關係。

## 第三條 契約期間

1. 本契約自雙方簽署之日起生效。
2. 甲方依服務工作範圍書選用第 0 階段者，第 0 階段於本契約成立日或雙方約定之第 0 階段啟動日正式啟動；標準完整申照專案於第 0 階段完成且甲方進入第 1 階段時正式啟動。甲方未選用第 0 階段者，標準完整申照專案於本契約成立日或雙方約定之啟動日正式啟動。各階段之啟動均不以乙方實際收到對應款項為條件。
3. 本契約有效至主管機關申請程序完成、雙方書面合意終止，或依本契約約定提前終止之日止。
4. 乙方應以合理專業注意義務及合理效率推進本服務，不承諾固定完成天數。因甲方資料、決策、內部窗口、利害關係人、會議安排、第三人、主管機關作業、法規變動或其他非可歸責乙方之因素造成延遲者，時程相應順延。
5. 本契約不設服務年度及自動續約。契約終止或屆滿後，保密、智慧財產、費用結算、損害賠償、爭議處理及依其性質應繼續有效之條款仍繼續有效。

## 第四條 服務範圍與服務工作範圍書

1. 本案實際選用之服務模組及服務範圍，以雙方簽署之服務工作範圍書為準。
2. 服務工作範圍書為本案詳細工作範圍之唯一依據，並負責界定各階段工作、交付成果、完成標準、工作與資料分工、財務資料分工、會議與執行方式、不包含事項及法規變動對工作範圍之影響。
3. 即使部分原始資料或草稿由甲方或第三人準備，只要乙方仍負責正式申請，乙方仍保有合理之審閱、一致性檢查、要求補正及判斷是否適宜送件之專業權限。
4. 服務工作範圍書未列入之工作，不因與售電業申照、能源交易或甲方營運相關而自動納入本服務。

## 第五條 服務費、請款及第三方費用

1. 甲方依服務工作範圍書選用第 0 階段者，第 0 階段服務費為 **NT$150,000 未稅**，不包含在標準完整申照專案總價內。第 0 階段正式啟動時，該服務費全額成為可請款款項；第 0 階段之啟動不以乙方實際收到該款項為條件。
2. 標準完整申照專案總服務費為 **NT$450,000 未稅**，付款節點如下：

   | 款次 | 金額（未稅） | 付款節點 |
   | --- | ---: | --- |
   | 第一筆 | NT$100,000 | 標準完整申照專案／第 1 階段正式啟動 |
   | 第二筆 | NT$200,000 | 第 1 階段完成，第 2 階段啟動 |
   | 第三筆 | NT$150,000 | 主管機關申請程序完成 |
   | 合計 | **NT$450,000** |  |

3. 甲方未選用第 0 階段時，前項第一筆 NT$100,000 於本契約成立及標準完整申照專案正式啟動時成為可請款款項。甲方選用第 0 階段時，本契約成立後僅就第 0 階段 NT$150,000 請款；第 0 階段完成且甲方進入第 1 階段時，標準完整申照專案正式啟動，第一筆 NT$100,000 始成為可請款款項。
4. 乙方得於各付款節點成立後，以電子郵件、電子系統或書面方式交付發票及完整請款文件。除雙方另有書面約定外，甲方應於收到完整發票及請款文件之次日起十個工作日內，以轉帳方式付款。
5. 甲方如對請款內容有疑義，應於收到請款文件後五個工作日內通知乙方並具體說明；逾期未提出者，視為對請款內容無異議。僅部分有疑義時，不影響無爭議部分之付款期限。
6. 本契約所載金額均為未稅金額，甲方應另行負擔依法應加計之營業稅。
7. 政府規費、第三方專業費用、認證或簽證費、郵寄、快遞、印製、翻譯、金融機構費用，以及因現場服務所生之必要合理差旅支出與其他因甲方案件所生之必要支出，均不包含於服務費。由乙方代墊者，甲方應依憑證或付款證明實報實銷。
8. 單筆金額較高或非通常可預期之支出，乙方應於可行情形下事前通知甲方；因時效、主管機關要求或其他合理原因無法事前通知者，乙方得於必要範圍先行處理並事後說明。
9. 甲方不得以其與主管機關、交易相對人、供電來源、售電對象或其他第三人間之爭議，拒絕或延遲支付已到期且無爭議之款項。
10. 任何折讓、例外付款或其他價格調整，均須由雙方以書面明確同意。

## 第六條 雙方權利義務

### 一、甲方義務

1. 指定具適當權限之主要聯絡窗口，負責資料提供、內容確認、決策傳達及內部協調。
2. 依乙方提出之合理期限，提供完整、正確、合法、最新且盡量符合未來真實營運之文件、資訊、數據及商業假設。
3. 就申請主體、事業定位、商業模式、電源、售電對象、組織、人力、財務、交易及最終申請內容作成並傳達決策。
4. 對其提供或確認之資料、數據、指示、決策、商業假設及簽署文件之真實性、完整性、正確性、合法性及最終採用負責。
5. 取得乙方執行本服務所需之內部批准，以及第三方資料、機密資訊或受保密義務拘束資訊之合法使用及揭露授權。
6. 依需要完成確認、補正、簽章、用印、付款、委任、授權及其他必要決策，並及時提供主管機關或其他相關主體直接通知甲方之重要資訊。

### 二、乙方義務

1. 依本契約及服務工作範圍書，以合理專業注意義務及合理效率提供服務。
2. 依甲方提供及確認之資料與決策，完成選用服務模組之約定工作及交付成果。
3. 發現資料或文件有明顯缺漏、錯誤、矛盾、不符合申請架構或與已確認營運規劃不一致時，通知甲方補正、說明或確認。
4. 依約辦理或協助辦理正式送件、主管機關意見處理、文件修正、補件及進度追蹤。
5. 於知悉可能重大影響本次申請之法規、政策或主管機關要求變動時，在合理範圍內通知甲方並說明影響。

## 第七條 成果確認及完成之法律效果

1. 各階段之交付成果及工作完成定義，以服務工作範圍書為準。
2. 甲方應於收到乙方第 0 階段或第 1 階段交付成果之日起十個工作日內完成確認，或提出具體且合理之修正意見；逾期未提出者，視為該階段交付成果已完成確認，乙方得依約請款或進入下一階段。
3. 甲方提出之修正意見應具體指出需修正之內容，並以原工作範圍及已確認之資料、假設與方向為基礎。甲方後續變更已確認事項而造成重大重作者，依第九條辦理。
4. 乙方交付第 0 階段成果並完成匯報會議後，甲方尚未決定是否申請、尚未採用特定方案或尚未作成特定商業決策，不影響第 0 階段之完成認定。
5. 乙方完成第 1 階段約定工作、形成可進入正式主管機關申請程序之完整申請架構並交付甲方後，主管機關是否受理、接受或核准，不影響第 1 階段之完成認定。
6. 主管機關申請程序完成時，第三筆正常付款節點成立；但甲方主動中止、本契約提前終止，或程序終結係因可歸責於乙方之重大違約所造成時，應依本契約之暫停、終止、責任及結算條款辦理，不逕視為第三筆正常付款節點成立。
7. 後續因甲方資料或決策、第三方未配合、主管機關審查或作業、法規政策變動，或其他非可歸責乙方之事由所生之延遲、修正、補件、程序中止或不利結果，不影響乙方已依約完成服務之認定。

## 第八條 非結果保證及責任限制

1. 乙方承諾完成約定之申請、送件、審查意見處理及補件支援，但不保證主管機關一定核准或核發執照、不保證於特定日期完成、不保證主管機關不要求補件，亦不保證主管機關接受甲方之特定商業模式。
2. 因下列事由造成之延遲、補件、修正、重新送件、程序中止、未獲核准或其他不利結果，如非可歸責乙方，不視為乙方違反本契約：
   1. 甲方未及時提供資料、確認、簽章、付款或作成必要決策。
   2. 甲方資料錯誤、不完整、過期、違法或前後不一致。
   3. 第三方未配合，或其資料、承諾或作業發生變更。
   4. 主管機關之審查、處理、系統、時程或裁量因素。
   5. 法令、政策、申請要求、表單或實務作業方式變更。
   6. 其他非可歸責乙方之事由。
3. 乙方得依服務工作範圍書提供售電業營運經驗、申請資料說明及文件整合服務，但不擔任甲方之律師、會計師、財務簽證人、審計人、工程技師或其他依法應具專門資格之人員，亦不對甲方財務預估或商業結果提供保證。
4. 涉及法律、會計、稅務、簽證、審計、工程、安全或其他依法應由特定專業人士提供之意見，甲方應另行委任適格人士。

## 第九條 服務變更與法規變動

1. 甲方提出服務工作範圍書以外之需求，或甲方變更已確認之重要資料、假設、申請方向或決策而造成重大重作時，乙方得提出工作範圍、時程及費用之調整。
2. 雙方應於乙方執行新增工作前，以書面確認新增工作範圍、交付成果、時程及費用。未完成書面確認前，乙方無義務開始新增工作。
3. 因法令、政策或主管機關要求所生之一般合理表單、格式及補充要求調整，由乙方依服務工作範圍書於原工作範圍內合理處理。
4. 前項變動如造成申請架構重大改變、已確認文件大幅重作、新增重大工作，或使甲方原商業模式根本無法繼續，乙方得暫停受影響工作並重新評估。雙方得另行書面約定追加服務，或依第十條及第十一條辦理暫停、終止與結算。
5. 乙方不負在原固定服務費內無限制承擔重大法規或主管機關要求變更所生工作之義務。

## 第十條 服務暫停

1. 甲方未提供必要資料、所提供資料有錯誤或遺漏、逾期、未確認、未簽章或未作必要決策時，乙方得以書面通知暫停全部或部分工作，服務時程並相應順延。前述暫停不影響乙方就已完成工作或已到期款項之請求。
2. 甲方逾期支付到期款項時，乙方得依法請求遲延利息並以書面通知甲方；甲方經通知後仍未於十個工作日內完成付款者，乙方得暫停全部或部分服務。因付款逾期而暫停者，專案時程相應順延，乙方不負因此造成之送件、補件、申請或其他時程延誤責任。持續或重大逾期付款時，乙方得依第十一條辦理終止。
3. 甲方於第 0 階段完成前主動要求暫緩，且非因乙方可歸責之重大違約者，第 0 階段 NT$150,000 仍為已到期服務費，不退款且不因暫緩而延後付款。暫緩期間原則上以三個月為限；甲方於三個月內恢復者，乙方依原工作範圍繼續執行。暫緩超過三個月者，乙方得依第十一條第四項終止契約，或由雙方另以書面重新確認後續工作安排；第 0 階段尚未完成者，不適用第十一條第五項之 NT$112,500 提前終止服務費。
4. 第 0 階段完成後，甲方因自身原因暫緩進入第 1 階段者，暫緩期間最多三個月。甲方於三個月內恢復並進入第 1 階段者，不適用 NT$112,500 提前終止服務費；暫緩超過三個月，或於暫緩期間明確表示不再進入標準完整申照專案者，依第十一條第五項辦理。
5. 甲方於第 1 階段進行中主動要求暫緩，且非因乙方可歸責之重大違約者，甲方應支付 **NT$100,000 未稅**之第 1 階段已投入工作階段結算款。該款同時抵充第五條第二項所定第二筆 NT$200,000 服務費之一部分。
6. 甲方於前項暫緩日起三個月內恢復履約者，第 1 階段完成時，第二筆服務費僅再支付未抵充之 **NT$100,000 未稅**。本款不增加標準完整申照專案總價，正常完成時總服務費仍為 NT$450,000 未稅。
7. 第 1 階段暫緩超過三個月、暫緩後甲方決定終止，或暫緩期間因法令、政策或主管機關要求變更致原申請無法繼續且非可歸責乙方者，依第十一條第六項辦理。
8. 第 2 階段暫緩期間，已到期款項不受影響。暫緩超過三個月或甲方於暫緩後決定不再續行者，依第十一條第七項辦理。

## 第十一條 契約終止及專案結算

1. 任一方重大違反本契約時，他方得以書面通知違約方，限期十個工作日改善；違約方屆期仍未改善，致專案無法合理繼續者，他方得以書面終止本契約。
2. 如重大違約性質無法改善，或繼續履約將使他方承受重大法律風險者，他方得不經前項改善期間，以書面立即終止本契約。
3. 雙方得隨時以書面合意終止本契約，並另行約定終止日、服務交接及費用結算方式。
4. 第 0 階段完成前，如甲方主動終止、決定不再繼續，或因可歸責甲方之事由致契約無法繼續，且非因乙方可歸責之重大違約者，第 0 階段 NT$150,000 為已到期服務費，甲方應支付且不得要求退款；除依法應負擔之稅額、已核准代墊及第三方費用外，不另收取第五項之 NT$112,500 提前終止服務費。
5. 第 0 階段已完成，但甲方其後決定不再進入原已選定之標準完整申照專案，或依第十條第四項暫緩超過三個月，或於暫緩期間明確表示不再進入標準完整申照專案，且非因乙方可歸責之重大違約者，視為甲方提前終止後續標準完整申照專案。除已到期之第 0 階段 NT$150,000 外，甲方另應支付 **NT$112,500 未稅**之提前終止服務費，另加依法應負擔之稅額、已核准代墊及第三方費用。
6. 第 1 階段進行中，如甲方主動終止、因可歸責甲方之事由致乙方依法或依約終止，或發生第十條第七項之情形，且非因乙方可歸責之重大違約者：
   1. 第五條第二項所定第一筆 NT$100,000 為已到期之專案啟動服務費。
   2. 甲方另應支付第 1 階段提前終止服務費 **NT$175,000 未稅**。
   3. 截至終止日之標準服務費總應結算為 **NT$275,000 未稅**，另加依法應負擔之稅額、已核准代墊及第三方費用。
   4. 甲方如已依第十條第五項支付 NT$100,000 階段結算款，該款抵充本項之第 1 階段提前終止服務費；抵充後尚餘 **NT$75,000 未稅**應付，不得重複收取。
7. 第 1 階段完成且第 2 階段開始後，如有下列情形之一，且非因乙方可歸責之重大違約者：
   1. 主管機關提出要求，甲方決定不接受並停止申請。
   2. 甲方主動要求暫緩且逾三個月未恢復。
   3. 暫緩期間因法令、政策或主管機關要求變更致原申請無法繼續，且非可歸責乙方。
   4. 其他由甲方主動中止且非可歸責乙方之合理同類情形。

   前述情形下，第五條第二項所定第一筆及第二筆合計 NT$300,000 均為已到期服務費，甲方另應支付第 2 階段提前終止服務費 **NT$75,000 未稅**；截至終止日之標準服務費總應結算為 **NT$375,000 未稅**，另加依法應負擔之稅額、已核准代墊及第三方費用。
8. 第四項至第七項之結算機制，不適用於乙方可歸責之重大違約造成專案無法合理繼續，且乙方經第一項改善期限仍未改善而由甲方終止之情形。此時：
   1. 甲方僅就終止前乙方已完成、可供甲方合理使用且合理應計價之服務，以及已核准之必要代墊與第三方費用辦理結算。
   2. 乙方應返還已收款中可明確歸屬於尚未提供，或因乙方重大違約而無法合理使用之服務部分。
   3. 雙方應依已交付成果、工作紀錄、各階段完成程度及預付款歸屬，以誠信原則完成結算。
9. 第 1 階段正式啟動後，第五項 NT$112,500 提前終止服務費不再適用；其後之暫緩、提前終止及結算，完全依第十條第五項至第八項及本條第六項至第八項辦理，不得重複加收 NT$112,500。
10. 契約終止不影響終止前已發生之權利、付款義務及損害賠償請求。乙方應於甲方結清無爭議之到期款項後，以合理方式交付甲方原始提供且仍由乙方持有之案件資料；依法或依內部合規要求須留存者，不在此限。

## 第十二條 保密

1. 本契約所稱機密資訊，指任一方因本契約之協商、簽署或履行而自他方取得之未公開資訊，包括但不限於公司、股東、組織、營運、系統、內部流程、電源、供電來源、售電客戶、其他交易相對人、受保密協議拘束之資訊、商業模式、價格、交易條件、申請策略、契約內容、財務、會計、稅務、資金、成本、收入及預估資料，以及依法或依其性質應合理認定為機密之其他資訊。
2. 接收方僅得為履行本契約之目的使用機密資訊，未經揭露方事前書面同意，不得向無須知悉之第三人揭露。
3. 接收方得於履行本契約所必要之範圍，向其員工、受任人、專業顧問、協力廠商及主管機關揭露機密資訊，但應使受領者承擔適當保密義務。
4. 下列資訊不受前述限制：接收時已合法公開、非因接收方違約而公開、接收方原已合法持有、自有權揭露之第三人合法取得，或接收方未使用機密資訊而獨立開發之資訊。
5. 因法令、法院或主管機關要求必須揭露時，接收方得在必要範圍揭露；如依法可事先通知，應於揭露前通知揭露方。
6. 任一方未經他方事前書面同意，不得公開使用他方名稱、商標、標誌或合作關係作為行銷、案例或對外宣傳。
7. 本條保密義務於本契約終止或屆滿後持續五年；屬營業秘密或依法應持續保密者，於該資訊喪失機密性前持續有效。

## 第十三條 智慧財產權

1. 甲方原始提供之資料及其原有智慧財產權，仍歸甲方或原權利人所有。
2. 乙方於本契約成立前已持有，或於履約中形成之通用方法、標準流程、文件架構、範本、工具、公式、模型、資料結構、專業知識及其改良，相關權利仍歸乙方所有。
3. 甲方付清本契約全部到期款項後，得為自身本次申請、內部決策、後續合規及自身售電事業營運目的，使用乙方依甲方個別資料製作之專案交付成果。
4. 除雙方另有書面約定外，前項使用權不包括將乙方通用方法、範本或工具單獨出售、授權、公開散布，或用於向第三人提供相同或類似顧問服務。

## 第十四條 損害賠償

1. 任一方違反本契約，經他方書面通知並給予合理改善期間而未改善者，應賠償他方因此所受之直接且可證明之實際損害。
2. 除乙方有故意、重大過失、違反保密義務、侵害智慧財產權，或法律另有不得限制之情形外，乙方因本契約對甲方所負之損害賠償責任總額，以損害事件發生前甲方依本契約已實際支付之服務費總額為上限。
3. 除因一方故意或重大過失所致外，任一方不對他方之間接損害、所失利益、預期交易利益、商譽損失或其他衍生性損害負責。
4. 甲方遲延支付到期款項時，乙方得依法請求遲延利息，並得依第十條暫停服務或依第十一條終止契約。

## 第十五條 不可抗力及不可歸責事件

1. 因天災、戰爭、重大疫情、政府行為、重大系統中斷或其他當事人無法合理預見、避免或控制之事件，致任一方不能或遲延履約者，受影響方就該影響範圍不負遲延或損害賠償責任。
2. 受影響方應於合理期間通知他方，說明影響範圍，並採取合理措施降低損害及恢復履約。
3. 事件僅影響部分義務時，未受影響部分仍應繼續履行；付款義務如在事件發生前已到期，不因本條而免除。
4. 法令、政策或主管機關要求變動之工作範圍與費用影響，優先依第九條處理；如因此暫停或終止，依第十條及第十一條結算。

## 第十六條 通知

1. 雙方依本契約所為之通知，應以書面、電子郵件或雙方同意之電子方式，送達本契約所載聯絡資料或指定窗口。
2. 聯絡資料變更時，變更方應通知他方；未通知者，他方以原聯絡資料所為之通知仍視為有效。
3. 涉及契約終止、重大違約、改善期限、服務暫停、工作範圍或費用變更之通知，應以可供日後查證內容及送達時間之方式為之。

## 第十七條 準據法及管轄

1. 本契約以中華民國法律為準據法。
2. 因本契約所生爭議，雙方應先以誠信協商解決；協商不成時，以臺灣臺北地方法院為第一審管轄法院。

## 第十八條 文件效力及完整合意

1. 服務工作範圍書、雙方簽署之契約修訂、變更單及其他明確納入本契約之書面文件，均為本契約之一部分。簽約前提供之報價單僅供內部評估及商務討論，除經雙方於本契約或其他書面文件中明確納入外，不單獨構成本契約之一部分。
2. 文件內容如有牴觸，就服務模組選擇、詳細工作範圍、交付成果、完成標準、工作分工及執行方式，以服務工作範圍書為準；就費用、付款、稅費、第三方費用、成果確認之法律效果、暫停、終止、結算、責任、保密、智慧財產及其他法律或商務條件，以本契約本文為準。雙方較後簽署之契約修訂或變更單，就其明確變更之事項優先適用。
3. 本契約之修訂、工作範圍變更、價格調整、折讓或例外安排，應以雙方書面同意為之。
4. 本契約及其附件構成雙方就本服務之完整合意，並取代簽署前就相同事項之口頭或書面約定。
5. 任一條款被認定全部或一部無效時，不影響其他條款之效力；雙方應以最接近原條款目的之有效約定取代。
6. 任一方未即時行使本契約權利，不構成權利拋棄。
7. 未經他方事前書面同意，任一方不得移轉本契約之全部或主要權利義務。但因合併、組織重整或營業概括承受所生之移轉，不在此限；移轉方應事前通知他方。
8. 本契約正本一式二份，雙方各執一份；採電子簽署者，電子文件與紙本具有相同效力。
